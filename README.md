# Skin Analysis & Recommendation System

This project is a skin analysis and recommendation system that uses deep learning to identify common skin issues from images/videos and provide suitable skincare recommendations.

## Features

* Skin issue detection using YOLOv11
* Skin analysis from uploaded images/videos
* Personalized skincare recommendations
* Hybrid recommendation system using content-based and collaborative filtering
* Flask-based backend

## Technologies Used

* Python
* YOLOv11
* Flask
* HTML
* CSS
* Machine Learning

## How to Run

1. Clone the repository
2. Install the required dependencies:

```bash
pip install -r requirements.txt
```

3. Run the Flask application:

```bash
python app.py
```

4. Open the local URL provided by Flask in your browser.
